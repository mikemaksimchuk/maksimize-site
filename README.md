# Maksimize Learning

A static, multi-page website prepared for GitHub Pages. No build step, account system, Base44 services, or server-side dependencies.

## Publish on GitHub Pages

1. Extract this ZIP and upload its contents to the root of your GitHub repository. Keep the assets and downloads folders intact.
2. In repository Settings → Pages, choose Deploy from a branch, your main branch, and the root folder.
3. Save and wait for GitHub to show the published URL. A custom domain can be configured in the same settings.

All internal links use relative paths and work under a GitHub repository subpath. Each section is a real HTML page. Navigation works without JavaScript.
